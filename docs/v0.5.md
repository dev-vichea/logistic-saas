# Mekong v0.5 — Document Intelligence & Document Center

## Delivered Changes

v0.5 introduces an automated trade document processing vault, a multilingual regional trade dictionary (Chinese / Khmer / English), and a cross-document reconciliation engine into the Mekong Logistics SaaS ecosystem. It streamlines international trade intake for Cambodia and regional cross-border corridors, turning unstructured and bilingual supplier documentation into operational cargo manifests.

* **Multi-Tenant Document Vault (`trade_documents`)**:
  * Centralized document repository supporting `commercial_invoice`, `packing_list`, `bill_of_lading`, `cdc_master_list`, `delivery_order`, and `customs_declaration`.
  * Tracks document numbers, original file storage, file sizes, MIME types, processing statuses (`uploaded`, `parsing`, `parsed`, `reconciled`, `flagged`, `verified`, `error`), and AI confidence scores.
  * Header attribute extraction: supplier/shipper, consignee, invoice dates, contract numbers, ports of loading/discharge, vessel/voyage, container numbers, and seal integrity references.
* **Regional Trade Lexicon & Chinese-to-English Normalization**:
  * Built-in dictionary covering industrial garment manufacturing, machinery, fabric, trim, and hardware terms:
    * `工业缝纫机` $\to$ `Industrial Sewing Machine`
    * `自动模板机` $\to$ `Automatic Template Sewing Machine`
    * `堆垛架` $\to$ `Stacking Rack`
    * `周转车` $\to$ `Material Handling Trolley`
    * `金属拉链` $\to$ `Metal Zipper`
    * `梭织布` $\to$ `Woven Fabric`
    * `织带` $\to$ `Webbing Tape`
    * `纽扣` $\to$ `Button`
* **Extracted Line Items Registry (`trade_document_items`)**:
  * Granular line item extraction capturing original descriptions (Chinese/Khmer), English normalized descriptions, HS classifications, quantities, units of measure (`PCS`, `SET`, `ROLL`, `KG`, `METER`), unit prices, subtotals, package counts, packaging types (`wooden_crates`, `cartons`, `bundles`), gross/net weights, and CBM volumes.
  * Line item edit interface allowing human-in-the-loop review and corrections.
* **Cross-Document Reconciliation Engine (`document_reconciliations`)**:
  * 5-tier pairing heuristic matching Commercial Invoices against Packing Lists.
  * Automated discrepancy detection:
    * Quantity variance between invoice and packing list.
    * HS classification differences and unit mismatches.
    * Missing packaging details (unpacked lines or missing gross weights).
    * Header metadata discrepancies (consignee, supplier, or invoice vs contract number).
    * Total cross-document volume and weight balance checks.
  * Status lifecycle: `balanced` (100% clean match), `has_discrepancies` (discrepancy alerts flagged for staff review), `resolved` (human-accepted variance with audit trail).
* **1-Click Sync to Shipment Cargo Manifest**:
  * Converts approved and verified document items directly into operational `cargo_items` on the linked shipment, eliminating repetitive manual data entry.
* **Interactive Frontend Dashboards & Review Studios**:
  * `/documents`: Document Center Vault with document type tabs, AI confidence meters, and modal document intake with quick-load sample data (`26TKYM164`).
  * `/documents/[document]`: Detailed document view with header metadata breakdown, confidence metrics, and editable line item data grid.
  * `/documents/reconciliation`: Cross-Document Reconciliation Studio with side-by-side comparison grid, variance tags, discrepancy alerts, and 1-click cargo sync.

## Concurrency & Tenant Security

* **Scoped Tenant Routing**: All document endpoints are nested under `/api/v1/organizations/{organization}/documents/` and resolved via `ResolveOrganization` with an immutable `OrganizationContext`.
* **Composite Foreign Keys**: Strict PostgreSQL foreign keys `(organization_id, ...)` prevent cross-tenant referencing of documents, line items, or reconciliations.
* **Organization Transaction Locking**: Write operations acquire row-level locks (`OrganizationActions::mutate`) to prevent concurrency races.
* **Adversarial Cross-Tenant Tests**: Validated with feature tests ensuring foreign tenants receive `404 Not Found` when attempting to access, update, delete, or sync another organization's trade documents.
