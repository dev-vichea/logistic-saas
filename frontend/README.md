# Next.js workspace

See the [project README](../README.md) for full setup. This App Router application uses Next.js 16, TypeScript, Tailwind CSS 4 and shadcn/ui with Radix.

`npm run dev`, `npm run lint`, `npm run typecheck`, `npm run build` and `npm run test:e2e` are the main scripts. API routes are proxied to the Laravel upstream configured with `API_INTERNAL_URL`.
